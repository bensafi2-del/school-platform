# ميزة الاستيراد الذكي للعلامات

## المعمارية

- الواجهة الحالية: index.html.
- OCR ومعالجة الملفات: خدمة Python/FastAPI منفصلة في ocr-service.
- قاعدة البيانات: تستعمل الجداول الحالية students وgrades كما هي.
- لا تحتاج المرحلة الأولى إلى migration جديد؛ المعاينة مؤقتة والحفظ النهائي يستخدم save_grade_field الموجودة حاليًا.

## مسار الاستخدام

1. المستخدم يسجل الدخول ويختار المؤسسة والفوج والمادة.
2. ترفع الواجهة المستند إلى خدمة OCR مع access token الحالي.
3. يتحقق الخادم من الجلسة والصلاحية عبر can_grade ويقرأ القائمة عبر teacher_group_roster.
4. تعاد معاينة مؤقتة تشمل تصنيف المستند، العلامات المقترحة، درجات الثقة، المصدر، وأسباب المطابقة.
5. يراجع المستخدم القيم ويحدد التلاميذ غير المؤكدين يدويًا.
6. بعد التأكيد فقط، تستدعي الواجهة save_grade_field لكل حقل غير فارغ.

## حدود النسخة الأولى

- استخراج الجداول من XLS/XLSX وDOCX وجداول PDF والصور.
- OCR للصور وملفات PDF الممسوحة.
- دعم العناوين العربية والفرنسية الشائعة.
- لا تعتمد المطابقة التقريبية للاسم آليًا.
- لا يوجد حفظ آلي أو تخزين طويل الأجل للمستندات.
- التخطيطات غير المعتادة والكتابة اليدوية تتطلب مراجعة يدوية.

## الأمن والتشغيل

راجع ocr-service/README.md للتشغيل وإعداد المتغيرات والحدود والخصوصية. لا تضع أي مفتاح سري في index.html ولا تستخدم service_role.
