# خدمة استيراد العلامات الذكية

خدمة OCR ومعالجة مستندات محلية أو مستضافة ذاتيًا. لا تستخدم OCR مدفوعًا ولا تحفظ الملفات أو العلامات.

## الدعم في هذه النسخة الأولية

- صور PNG/JPEG/WebP/BMP/TIFF، وPDF متعدد الصفحات، وExcel XLS/XLSX، وWord DOCX.
- OCR محلي عبر Tesseract بالنماذج العربية والفرنسية والإنجليزية.
- تصحيح اتجاه EXIF، تقليل التشويش، تحسين التباين، وتصحيح الميل البسيط.
- استخراج الجداول والعناوين العربية والفرنسية وتحويل الأرقام العربية الهندية.
- تصنيف مبدئي لكشف العلامات مع أسباب القرار ودرجة ثقة تقريبية.
- مطابقة حرفية فقط مع اسم التلميذ ورقم ترتيبه. لا توجد مطابقة تقريبية تلقائية.
- التحقق من المستخدم والصلاحية عبر جلسة Supabase الحالية ودوال النظام الموجودة.
- الملفات تعالج في الذاكرة ثم تُهمل؛ لا يوجد تخزين ملفات أو نتائج في هذه الخدمة.

## التشغيل المحلي

1. انسخ .env.example إلى .env.
2. ضع عنوان مشروع Supabase ومفتاحه publishable فقط.
3. اضبط CORS_ORIGINS على عنوان موقع المنصة.
4. شغّل:

    docker build -t school-grade-import .
    docker run --rm --env-file .env -p 8080:8080 school-grade-import

5. تحقق من http://localhost:8080/health.
6. داخل «الاستيراد الذكي» في المنصة استخدم عنوان الخدمة http://localhost:8080.

عند الاستضافة خارج جهازك استخدم HTTPS، واختر مزودًا تتحكم فيه وتثق به. لا تعرض الخدمة للإنترنت بلا تحديثات وضبط CORS وحماية من إساءة الاستخدام.

## API

POST /api/v1/grade-import/preview (multipart/form-data)

الحقول:
- school_id
- group_id
- subject_id
- files (متكرر لكل ملف)

الرأس المطلوب:
- Authorization: Bearer <Supabase access token>

يتحقق الخادم من الرمز عبر Supabase Auth ثم يستدعي can_grade وteacher_group_roster بهوية المستخدم نفسها. لا يحتاج إلى service key.

## الحدود الافتراضية

- 8 ملفات في الطلب.
- 15 MB لكل ملف، و45 MB للطلب.
- 20 صفحة PDF أو إطار صورة.
- 28 مليون بكسل للصورة الواحدة.
- 10000 صف لكل ورقة Excel.

هذه حدود أولية؛ راقب CPU/RAM واضبط rate limiting على مستوى المضيف.

## الدقة والخصوصية

هذه نسخة أولية ولا تضمن دقة OCR أو اكتشاف الجدول لكل تصميم. الجداول المطبوعة المنتظمة أفضل عادةً من الصور المائلة أو الكتابة اليدوية. درجات الثقة مؤشرات فرز وليست احتمالات إحصائية معايرة. راجع كل قيمة ومصدرها يدويًا، وأكد هوية التلميذ عند أي غموض.

لا تُرسل المستندات إلى مزود OCR خارجي. لا تحفظ الخدمة الملفات أو نواتج OCR. تستقبل فقط قائمة التلاميذ الضرورية للمطابقة من دوال Supabase المحمية. استضافة الخدمة وموارد CPU/RAM قد تكون مدفوعة لدى مزود الاستضافة، رغم أن مكونات OCR مفتوحة المصدر ومجانية. للبيانات المدرسية استخدم تشغيلًا محليًا أو خادمًا خاصًا، مع HTTPS، تحديثات دورية، وعدم الاحتفاظ بسجلات تحتوي محتوى حساسًا.
